# План: субагент и скиллы для создания протокола встречи из видео

Проект пустой — создаем всё с нуля. Распознавание: локальный Whisper. Формат отчета: Markdown. Путь к папке с видео — в `.env`.

## 1. Структура папок (по AGENTS.md)
- `script/` — скрипты
- `artifact/` — готовые отчеты и расшифровки
- `temp/` — временные файлы (в т.ч. аудио-вырезки)
- `.gitignore` — исключить `temp/` и `.env`

## 2. Конфигурация
- `.env` — переменная `VIDEO_FOLDER` (путь к папке с видео, пользователь заполнит/уточнит)
- `.env.example` — шаблон с комментарием

## 3. Скрипты (script/)
1. **`transcribe_meeting.py`** — принимает путь к видео, через ffmpeg извлекает аудио во `temp/`, запускает локальный Whisper (модель `medium`, язык `ru`, вывод с таймкодами), сохраняет расшифровку в `artifact/<имя_видео>_transcript.md`, печатает длительность видео.
2. **`create_report.py`** — генерирует итоговый Markdown-отчет в `artifact/` по требуемой структуре:
   - Таблица: Повестка / Дата встречи (ДД.ММ.ГГГГ ЧЧ:ММ) / Длительность (мин) / Организатор (пусто) / Участники (пусто) / Место встречи (из входных данных);
   - Раздел «Итоги, решения, дальнейшие действия» с таблицей: Принятое решение / Ответственный / Ожидаемая дата выполнения.
   - Скрипту передаются: путь к расшифровке, место встречи, повестка, список решений (дату и длительность скрипт берет из метаданных видео через ffprobe).

## 4. Скилл
**`.zcode/skills/meeting-report/SKILL.md`** — описание рабочего процесса субагента:
- Триггеры: «дай протокол», «распознай встречу»;
- Шаги: прочитать `VIDEO_FOLDER` из `.env` → показать список видео и спросить, какой файл обрабатывать → спросить переговорную комнату → запустить `transcribe_meeting.py` → проанализировать расшифровку (повестка, решения, ответственные, сроки — извлекает сам агент из текста расшифровки) → вызвать `create_report.py` → вернуть пользователю путь к отчету.
- Пользователь дозаполняет «Организатор» и «Участники» в готовом файле.

## 5. Субагент
**`.zcode/agents/meeting-reporter.md`** — определение субагента: назначение, ссылка на скилл и скрипты, правила (не выдумывать данные, если в расшифровке нет ответственного/срока — ставить прочерк и сообщать пользователю; соблюдать терминологию из AGENTS.md).

## 6. Зависимости
Проверить установку `ffmpeg` и Python-пакетов `openai-whisper` (или `faster-whisper`); при отсутствии — дать пользователю простую инструкцию по установке.

## Результат работы субагента
Markdown-файл в `artifact/` с двумя разделами требуемой структуры, плюс файл расшифровки рядом.
